# 像素課堂前端

學生在有紙張紋理的冒險手冊登記，封面用墨綠、磚橘和原創像素山景。開始後畫面以題幹和四個大選項為主，等待、暫停、回饋和結算各有明確下一步。
先驗證每單元十題、選項映射與冪等計分，再串本機房間、老師控制與只含暱稱和分數的排名快照。最後檢查整趟流程與響應式版面。
本機示範限同源瀏覽器，以 Web Locks 串行寫入。老師在分頁開啟時每十秒比對排名。雲端排名由授權老師發布雙頁公開快照；學生另讀同房公開分數作為寶箱目標清單，不能讀取同學的私人進度或答案。

## v2 計時與寶箱

老師大廳可設定 1–60 整數分鐘（預設 20），學生與老師均看到倒數。暫停保存餘時；時間到後只讀。答錯顯示 3 秒凍結與可閱讀詳解，凍結到期後可前進；詳解沒有分數獎勵。最後一題答錯需等凍結完成才結算。

答對後在題目內顯示三個外觀相同的像素寶箱，開啟前不顯示種類或獎勵。選擇後保存該寶箱結果，不能換箱或重抽。加分／扣分直接確認結算；偷分／交換先選同學並顯示目前公開分數，結算使用交易當下的分數。只有單人教室才改成 +20；零分同學仍是可選對象。最後一題答對需完成寶箱結算才顯示結果。完整權重見 [SPEC.md](../SPEC.md#4-game-mechanics)。

老師分享區提供原生分享、複製完整加入網址與可展開／放大的 QR。QR 使用本機套件延遲產生；複製失敗時保留可選取網址，不依賴遠端 QR 服務。本機示範與 localhost 網址均有裝置可用範圍提示。倒數更新不應搶走網址或時間欄位焦點，也不應關閉已展開的 QR。

舊雲端 v1 教室僅顯示回顧，提示另建新教室；本機 v2 與舊示範存檔分開。既有答案、題序、選項排列與寶箱結果在刷新後保留。上述為介面行為；實際瀏覽器、真實裝置與部署驗證仍須依當次結果回報。


## 老師房間控制

闖關中首屏顯示目前房間、狀態、剩餘時間、人數、玩家進度，以及墨綠實底「暫停作答」與磚橘外框「結束活動」。其他管理與排名預設收合；建立、切換、設定、封存與刪除等管理入口停用，使用中性樣式與一則可見原因，不只靠顏色或 tooltip。學生流程不受老師的管理限制影響。

刪除區放在房間詳情底部。原生 dialog 顯示固定目標碼與刪除範圍，輸入完整碼後才能送出；取消不寫資料。對話框不隨訂閱重建，保留輸入與焦點。按鈕至少 48px，小螢幕換行。刪除中顯示狀態，失敗可續刪，不使用假百分比。


示範老師在大廳編輯的時間草稿與輸入框焦點會跨學生加入等重繪保留；按「設定時間」成功後才清除草稿，離開大廳則依活動狀態顯示已保存設定。本機刪除標記區分 deleting 與 completed，失敗及刷新均顯示尚未完成與續刪入口，不把禁止重建誤報為已清空資料。
